比较链接：[五个上游提交](https://github.com/michelebergo/nina.plugin.aiweather/compare/e5d652423d468405f7ef9b7b61938bf9471439e5...70111eb8efb9e86c405d21fc6fafeb05c37ac8fd)。

| 内容 | ADVANCED 的实现 |
| --- | --- |
| 主题、列宽、编辑控件 | 合入 NINA 主题颜色与默认文字大小；相机表格采用有效的固定列宽；保留中文、本地模型及主从控件。活动日志保留等宽小字体。 |
| 30 秒节流 | 仅同一连接内的重复立即检查可复用有效结果；在分析互斥锁内判断，先执行太阳高度保护。配置变更、失败结果、时钟倒退和过期结果不可复用；不更新原分析时间，不跳过从节点网络轮询。 |
| 断开重连 | 不采用跨连接缓存 SAFE 的做法。继续清空安全判定并从不安全开始，必须得到新结果。原有定时检查不因节流而取消。 |
| 取消 | 用户停止的取消沿 RTSP/在线模型/ONNX 路径传播；不冒充 API 超时或触发本地回退。定时器绑定创建时的取消令牌，旧回调不能借用新连接令牌继续运行。 |
| 本地模型失败 | 保留失败来源元数据，使学生失败不阻断有效在线教师；但无效最终结果不覆盖上次测量、不更新时间、不进入数据集或安全状态计算。原结果仍受既有最大数据年龄限制，超时转不安全。有效本地回退仍按现有规则使用。 |
| 凭据 | 新建相机行继承本机已保存的账号；RTSP/HTTP 启动时空字段不擦除已有凭据。保留主相机行显式编辑/清除的原有路径。不改变凭据同步协议，不在文档或日志输出凭据。 |
| RTSP 会话 | 不采用上游每次分析另开 FFmpeg 会话再关闭的方案。保留优先复用已有 LibVLC 预览；需要独立后端时持续排空视频流、只取更新且新鲜的帧。双端预览、接管、断流恢复策略不变。 |
| VLC 日志 | 降低时钟等重复诊断的日志级别；晚帧检测先经过现有健康监视器，保留聚合告警与自动恢复，不能因降噪屏蔽卡死检测。 |
| 清单发布工作流 | 可选清单 PR 分支直接基于官方 upstream/main；不移植强制改写 fork main 的操作。此发布不要求向 NINA 官方提交清单。 |

Gemini 免费池的顺序、各模型独立额度电路、跨模型继续尝试，以及普通 Gemini 单请求策略均保留。内置 ONNX 权重未变，训练数据、RRCI、屋顶控制及用户配置不在本次修改范围内。

## 验证

- 非在线 NUnit 测试：83 项通过，包括新增的节流边界、配置失效、无效读数、空凭据、ONNX 取消和免费池取消回归。
- DatasetSmoke 完整回归通过，覆盖共享 RTSP 会话、帧新鲜度、主从协议/接管、模型池及样本处理等既有行为。
- 模型请求使用模拟 HTTP；不消耗真实 API 额度，不连接真实摄像头或控制屋顶。
- WPF 及 Release 编译通过。没有启动 NINA 进行现场主题截图或真实断流验收，自动化测试不等于朋友机器实测。

## 安装与发布约束

- Windows x64 插件包：解压后上限 260 MiB、压缩包上限 180 MiB。
- 不携带其他操作系统或 x86/ARM64 库、测试输出、开发环境、数据集、用户配置或密钥。
- 安装前检查 NINA 已关闭，将旧版移到插件扫描目录之外留作回滚，再替换并校验文件。
- 保持 NINA 关闭；之后手动启动时加载新版。具体产物大小及安装校验结果以 Release 附件和交付记录为准。
